# Assistente Musical por Voz

Projeto de TCC desenvolvido em Flutter para apoiar a produção musical independente por comandos de voz em dispositivos Android.

## Projeto principal

O código-fonte, instruções de execução, arquitetura e funcionalidades estão na pasta:

➡️ [Abrir README completo do aplicativo](./app_voz/README.md)

## Tecnologias principais

- Flutter e Dart
- Android
- SQLite
- Reconhecimento e comandos de voz
- Google Sign-In / Firebase
