================================================================================
PARTE B: ROTEIRO MANUAL PARA O AMIGO EXECUTAR NO OVERLEAF
================================================================================

Ola! Segue o roteiro completo para atualizar o TCC no Overleaf.
Leia tudo antes de comecar. Nao pule etapas.

--- PRE-REQUISITOS ---

1. Tenha acesso ao projeto no Overleaf do TCC.
2. Baixe uma copia de seguranca ANTES de qualquer edicao:
   Overleaf -> Menu -> Download -> Source (zip)
3. Tenha este pacote de arquivos TXT aberto em outro monitor ou aba.
4. Acesse o arquivo correto para cada edicao (ver PARTE A deste arquivo).

--- ETAPA 1: DIAGRAMAS PlantUML ---

1. Abra o arquivo 04_DIAGRAMAS_PLANTUML_PARTE_1.txt deste pacote.
2. Para cada diagrama (8.1 a 8.7), copie o bloco entre @startuml e @enduml.
3. Cole em: https://www.plantuml.com/plantuml/uml/
4. O site exibe a imagem do diagrama automaticamente.
5. Clique com o botao direito na imagem -> Salvar como PNG.
6. Use o nome de arquivo indicado em cada secao (ex: diagrama-caso-uso-touchless-v2.png).
7. Repita para todos os diagramas do arquivo 05_DIAGRAMAS_PLANTUML_PARTE_2.txt (8.8 a 8.15).
8. Suba todos os PNGs gerados para o Overleaf (botao Upload na aba de arquivos).

--- ETAPA 2: PRINTS DE TELA ---

1. Abra o aplicativo TouchLess no celular Android.
2. Para cada item da lista de prints no arquivo 06_PRINTS_LEGENDAS_E_QUADROS.txt:
   - Navegue ate a tela indicada.
   - Configure o estado necessario (ver "Estado necessario" de cada print).
   - Tire o print (botao Volume Baixo + Liga/Desliga simultaneamente no Android).
   - Transfira o print para o computador (USB ou Drive).
   - Renomeie o arquivo com o nome indicado (ex: tela-boas-vindas.jpeg).
3. Suba todos os prints para o Overleaf.

--- ETAPA 3: EDITAR O MAIN.TEX ---

Siga a ordem indicada na PARTE A deste arquivo ([1] a [20]).
Para cada item:
  a. Abra o main.tex no Overleaf.
  b. Use Ctrl+F para localizar o trecho que deve ser alterado.
  c. Copie o texto novo do arquivo TXT indicado.
  d. Substitua o trecho antigo pelo novo.
  e. Compile o PDF periodicamente para verificar se nao ha erros.

DICA: Nao altere tudo de uma vez. Edite secao por secao e compile.
Se aparecer erro de compilacao, desfaca a ultima alteracao e verifique o texto.

--- ETAPA 4: VERIFICACAO FINAL ---

1. Compile o PDF completo no Overleaf.
2. Verifique se todas as figuras aparecem corretamente.
3. Verifique se os quadros estao formatados corretamente.
4. Verifique se a numeracao de figuras e quadros esta correta.
5. Verifique se as referencias cruzadas (\ref{fig:...}) apontam para figuras existentes.
6. Salve uma copia final do PDF.

--- O QUE NAO FAZER ---

- Nao edite a capa, a folha de aprovacao ou os agradecimentos.
- Nao delete referencias bibliograficas existentes.
- Nao substitua imagens sem conferir o nome do arquivo no main.tex.
- Nao compile o projeto sem ter as imagens novas ja no Overleaf
  (causara erro "File not found").

--- EM CASO DE ERRO DE COMPILACAO ---

Os erros mais comuns:
  - "File not found: nome-imagem.png" -> Subir a imagem no Overleaf
  - "Undefined control sequence: \fontefigura" -> Manter o padrao de legenda existente
  - "Missing $ inserted" -> Verificar se acidentalmente adicionou underscore (_)
    sem o modo matematico. Substituir por \_ ou remover.
  - "Overfull hbox" -> Imagem muito larga; ajustar width para 0.6\textwidth
