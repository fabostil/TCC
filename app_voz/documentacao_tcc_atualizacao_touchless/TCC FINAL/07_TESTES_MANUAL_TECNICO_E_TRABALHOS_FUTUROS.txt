TITULO: MANUAL TECNICO DO APLICATIVO TOUCHLESS

1. REQUISITOS DE AMBIENTE DE DESENVOLVIMENTO

1.1 Software necessario:
  - Flutter SDK 3.x ou superior
  - Dart SDK 3.x (incluso no Flutter)
  - Android Studio Flamingo ou superior
  - Git 2.x
  - Java JDK 17 (para build Android)

1.2 Configuracao do ambiente:
  Apos instalar o Flutter SDK, configurar as variaveis de ambiente:
  - FLUTTER_HOME: caminho da pasta raiz do Flutter
  - PATH: incluir $FLUTTER_HOME/bin
  Verificar a instalacao com:
    flutter doctor

1.3 Dispositivo ou emulador Android:
  - Android versao 8.0 (API 26) ou superior
  - Permissao de instalacao de apps externos (para instalar o APK)

2. CONFIGURACAO DO PROJETO

2.1 Clonar o repositorio:
  git clone [url do repositorio]
  cd app_voz

2.2 Instalar dependencias Flutter:
  flutter pub get

2.3 Arquivos de configuracao necessarios:
  - google-services.json: obrigatorio para Google Sign-In
    Caminho: android/app/google-services.json
    Obtido no Firebase Console do projeto TouchLess
  INFORMACAO NAO CONFIRMADA: verificar se arquivo esta disponivel no repositorio
                              ou se precisa ser gerado.

3. EXECUCAO EM MODO DEBUG

3.1 Conectar dispositivo Android com depuracao USB ativa:
  - No Android: Configuracoes -> Opcoes do desenvolvedor -> Depuracao USB

3.2 Verificar dispositivo detectado:
  flutter devices

3.3 Executar o app:
  flutter run

3.4 O app sera instalado automaticamente no dispositivo.

4. BUILD DE PRODUCAO

4.1 Build APK de debug (para testes):
  flutter build apk --debug

4.2 Build APK de release (para distribuicao):
  flutter build apk --release
  AVISO: Requer arquivo de keystore configurado em android/key.properties

4.3 Saida do build:
  build/app/outputs/flutter-apk/app-debug.apk  (debug)
  build/app/outputs/flutter-apk/app-release.apk (release)

5. BANCO DE DADOS

5.1 Localizacao: banco de dados local no dispositivo (SQLite)
  Nao e necessario configurar banco externo.
  O banco e criado automaticamente na primeira execucao.

5.2 Versao atual do esquema: 10
  Migrations sao executadas automaticamente ao abrir o app
  caso o banco seja de versao anterior.

5.3 Para resetar o banco (testes):
  - Desinstalar o app no dispositivo (remove banco automaticamente)
  - Ou limpar dados: Android -> Configuracoes -> Apps -> TouchLess -> Limpar dados

5.4 Tabelas do banco:
  usuario, projeto, gravacao, comando_voz, comando_personalizado,
  historico_acao, configuracao_app

6. PERMISSOES DO ANDROID

O app requer as seguintes permissoes (declaradas em AndroidManifest.xml):
  - RECORD_AUDIO: para reconhecimento de voz e gravacao de audio
  - READ_EXTERNAL_STORAGE: para leitura de arquivos de audio
  - WRITE_EXTERNAL_STORAGE: para salvar arquivos de audio
  - INTERNET: para Google Sign-In (quando usado)

A permissao de microfone e solicitada dinamicamente na Tela de Permissao
de Microfone durante o onboarding.

7. COMANDOS DE VOZ - CONFIGURACAO

7.1 O reconhecimento de voz utiliza o pacote speech_to_text,
que integra o motor STT nativo do Android.

7.2 Configurar idioma do reconhecimento:
  O app usa o idioma padrao do dispositivo. Para reconhecimento em
  portugues, o dispositivo deve ter o idioma configurado como
  "Portugues (Brasil)".

7.3 Escuta continua:
  Quando ativada, o sistema reinicia automaticamente a escuta apos
  cada comando. Pode ser ajustada em Configuracoes.

7.4 Flag experimental (voz em tempo real):
  O arquivo lib/features/voices/realtime/ contem implementacao
  experimental de gravacao de audio em pipeline isolado.
  NAO e ativado por padrao. Requer ajuste manual no codigo.
  INFORMACAO NAO CONFIRMADA: verificar flag de ativacao atual.

9. LIMITACOES CONHECIDAS

- Recuperacao de senha nao implementada nesta versao (trabalho futuro)
- Armazenamento somente local (sem sincronizacao em nuvem)
- Funciona apenas em Android (iOS nao testado)
- Reconhecimento de voz depende do motor STT do dispositivo
- Google Sign-In requer conexao com internet
- Edicao multipista nao disponivel (apenas gravacoes individuais)
- Wake-word sempre ativo nao disponivel (escuta ativada manualmente)

INICIO DO TEXTO

Como trabalhos futuros, identificam-se as seguintes oportunidades de extensao
e melhoria para o sistema TouchLess:

\begin{itemize}
    \item \textbf{Recuperacao de senha}: implementar o fluxo de recuperacao
    de senha por e-mail, permitindo que usuarios locais redefinam sua senha
    sem necessidade de novo cadastro. Esta funcionalidade nao foi implementada
    na versao atual por nao ser critica para o fluxo principal de uso.

    \item \textbf{Armazenamento em nuvem}: integrar servico de armazenamento
    em nuvem (ex.: Firebase Storage, Google Drive) para backup automatico das
    gravacoes e sincronizacao entre dispositivos.

    \item \textbf{Sincronizacao entre dispositivos}: permitir que o usuario
    acesse seus projetos e gravacoes em multiplos dispositivos com a mesma conta.

    \item \textbf{Wake-word sempre ativo}: implementar deteccao de palavra-chave
    de ativacao (ex.: "TouchLess"), possibilitando que o usuario ative a
    escuta por voz sem precisar interagir fisicamente com o dispositivo.

    \item \textbf{Melhoria do reconhecimento em ambientes ruidosos}:
    implementar filtragem e pre-processamento de audio para melhorar a precisao
    do reconhecimento de voz em ambientes com ruido de fundo.

    \item \textbf{Exportacao de gravacoes}: permitir que o usuario exporte
    gravacoes para outros formatos de audio (MP3, WAV) ou compartilhe
    diretamente para plataformas de distribuicao musical.

    \item \textbf{Versao iOS}: adaptar o aplicativo para o sistema operacional
    iOS, mantendo a mesma base de codigo Flutter.

    \item \textbf{Edicao multipista}: implementar funcionalidades de edicao
    de audio multipista, permitindo a sobreposicao e mixagem de gravacoes.

    \item \textbf{Colaboracao em tempo real}: permitir que multiplos usuarios
    colaborem em um mesmo projeto musical de forma remota.

    \item \textbf{Integracao com plataformas musicais}: integrar o app com
    plataformas de distribuicao musical (Spotify for Artists, SoundCloud,
    YouTube Music) para publicacao direta das gravacoes.

    \item \textbf{Aprimoramento da acessibilidade}: melhorar o suporte a
    leitores de tela e outras tecnologias assistivas para usuarios com
    deficiencias visuais ou motoras.

    \item \textbf{Reconhecimento de voz offline}: integrar modelo de
    reconhecimento de voz local que funcione sem conexao com internet.

    \item \textbf{Dashboard avancado}: expandir o dashboard com graficos
    de evolucao, tendencias de uso e estatisticas detalhadas de producao
    musical ao longo do tempo.
\end{itemize}
